Назначение и доступ к Google Drive

LestaReleaseSync — локальный Windows-агент для личной публикации архива установщика. Он получает разрешение владельца Google Drive, проверяет возможность редактирования конкретного файла, заменяет его содержимое и скачивает результат для проверки SHA-256. Текущий OAuth scope предоставляет чтение и запись Google Drive; реализация ограничивает операции заранее заданным ID файла зеркала.

Обрабатываемые данные

Приложение обрабатывает OAuth access token и refresh token, идентификатор файла, информацию о возможности редактирования, содержимое публикуемого архива и скачанные для проверки байты. Оно не запрашивает пароль Google, игровой пароль или игровые коды двухфакторной аутентификации.

Хранение и передача

Refresh token и настройки OAuth сохраняются на компьютере владельца с шифрованием Windows DPAPI для текущего пользователя. Временные токены используются для HTTPS-запросов к Google. Локально сохраняются журналы, контрольные суммы, состояние публикации и копии архивов. Скачанный владельцем исходный JSON OAuth хранится отдельно до его удаления владельцем.

Содержимое архива отправляется в Google Drive. Публичный архив доступен согласно установленным владельцем настройкам общего доступа. Приложение не меняет эти настройки. Страницы сайта размещаются на GitHub Pages; обращения к ним обрабатываются GitHub в соответствии с его собственной политикой. Аналитика, рекламные скрипты и формы сбора данных на этих страницах отсутствуют.

Использование данных

Данные Google используются исключительно для публикации и проверки указанного архива. Приложение не продаёт данные, не использует их для рекламы или обучения моделей и не передаёт токены в публичный архив. Google-агент не отправляет данные Google в Яндекс Диск; отдельный агент Яндекса публикует локальный комплект с отдельной авторизацией.

Отзыв доступа и удаление

Владелец может остановить фоновую задачу Windows и отозвать доступ приложения в настройках своего аккаунта Google. После этого можно удалить локальный файл google.dpapi, исходный JSON OAuth, журналы и рабочие архивы. Срок хранения локальных материалов определяется владельцем; автоматическое удаление по сроку не реализовано. Удаление локальных данных не удаляет опубликованный файл из Google Drive — его владелец удаляет отдельно.

Ограничения защиты

DPAPI защищает сохранённые токены, но процессы, имеющие доступ от имени того же пользователя Windows, могут получить доступ к этим данным. По вопросам доступа или удаления обращайтесь по указанной выше почте.
