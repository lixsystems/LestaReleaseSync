LestaReleaseSync

Личное приложение владельца для публикации обновлённого установщика модификаций «Мира танков».

Как работает приложение

Windows-агент замечает изменения локального комплекта, проверяет SHA-256 и заменяет содержимое заранее выбранного ZIP-архива в Google Drive. Существующая ссылка на архив сохраняется.

Google OAuth используется для разрешения записи владельцем Диска. Приложение не предоставляет доступ к игровому аккаунту и не запрашивает игровой пароль.

В текущей реализации запрашивается разрешение Google Drive на чтение и запись. Код обращается только к заранее заданному файлу зеркала, скачивает его для проверки и не перечисляет содержимое всего Диска.

Для кого

Приложение предназначено для личного использования владельцем проекта. Не является официальным продуктом Lesta Games, Wargaming или Google.
